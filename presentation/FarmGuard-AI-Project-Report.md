## 1. Introduction

FarmGuard AI is a full-stack smart agriculture web platform that uses Artificial Intelligence and Machine Learning to help farmers detect crop diseases early and receive actionable treatment recommendations. The platform is designed for small and marginal farmers in India who lack access to agricultural experts.

## 2. Problem Statement

Small farmers in India lose approximately 20–40% of their crops annually due to late detection of plant diseases. Rural areas have limited access to trained agricultural experts, and traditional diagnosis methods are slow, expensive, and often occur only after significant crop damage has occurred. Early identification of diseases is critical for saving crops, reducing financial losses, and improving farmer livelihoods.

## 3. Objectives

- Enable instant crop disease detection through photo upload
- Provide AI-powered confidence scores and severity classification
- Deliver practical treatment recommendations
- Offer a farmer dashboard with scan history and analytics
- Make precision agriculture accessible without expensive hardware

## 4. Proposed Solution

FarmGuard AI is a web-based platform where farmers can:

1. Register and login securely
2. Select crop type (Tomato, Rice, Potato, etc.)
3. Upload a photograph of an affected crop leaf
4. Receive instant AI analysis with disease name and confidence percentage
5. View severity level (Low, Medium, or High)
6. Read treatment and prevention recommendations
7. Track all scans on an analytics dashboard

## 7. System Architecture

- **Presentation Layer:** Next.js + React responsive web UI
- **Application Layer:** Node.js API routes for auth and AI processing
- **AI Layer:** Machine Learning model for image classification
- **Data Layer:** Client-side persistence for scan history

**Flow:** User uploads image → API processes → ML model analyzes → Results returned → Dashboard updated
